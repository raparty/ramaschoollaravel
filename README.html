Getting Started

Installation

Get up and running in minutes with these steps.

1

Clone the Repository

$ git clone https://github.com/raparty/ramaschoollaravel.git
$ cd ramaschoollaravel
2

Install Dependencies

$ composer install
$ npm install
3

Configure Environment

$ cp .env.example .env
$ php artisan key:generate

Then edit .env with your database credentials:

# MySQL
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=school_erp
DB_USERNAME=your_username
DB_PASSWORD=your_password
4

Run Migrations

$ php artisan migrate
$ php artisan db:seed   # optional: loads sample data
5

Link Storage & Set Permissions

$ php artisan storage:link
$ chmod -R 775 storage bootstrap/cache
6

Build & Serve

$ npm run build
$ php artisan serve

Visit http://localhost:8000 — default login: admin@school.com / password
